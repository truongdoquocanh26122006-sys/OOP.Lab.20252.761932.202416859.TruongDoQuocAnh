Question: Suppose the DVDs has a different ordering rule from the other media types, that is by title, then decreasing length, then cost. How would you modify your code to allow this?
- Ghi de code compareTo() nhu nay:
@Override
public int compareTo(Media other) {
    // 1. So sánh tiêu đề theo bảng chữ cái
    int titleDiff = this.getTitle().compareTo(other.getTitle());
    if (titleDiff != 0) return titleDiff;

    // 2. Nếu cùng tiêu đề, xét trường hợp cả hai đều là DVD để so sánh Length
    if (this instanceof DigitalVideoDisc && other instanceof DigitalVideoDisc) {
        DigitalVideoDisc d1 = (DigitalVideoDisc) this;
        DigitalVideoDisc d2 = (DigitalVideoDisc) other;
        
        // So sánh độ dài giảm dần (decreasing length)
        int lengthDiff = Integer.compare(d2.getLength(), d1.getLength());
        if (lengthDiff != 0) return lengthDiff;
    }

    // 3. Nếu vẫn bằng nhau hoặc không phải DVD, so sánh giá (giảm dần theo cost)
    return Float.compare(other.getCost(), this.getCost());
}
